# UMKM Hub Web

Next.js 15 ops UI — catalog, CRM, orders (PDF / e-Faktur prep), warehouse create+edit, targets, analytics, domain statistics, dictionary, dashboard, export/import, language, profile invoicing identity.

Docs **v1.5.233**.

## Local run

```bash
npm run setup && npm run sync
npm run api:dev
npm run web:dev   # → http://localhost:3000
```

## Key routes

`/login` · `/register` · `/forgot-password` · `/reset-password` · `/verify-email` · `/dashboard` · `/products` · `/customers` · `/orders` · `/warehouse` · `/targets` · `/analytics` · `/glossary` · `/profile`
